## 指标口径

- 发布评估器 `scripts/evaluation/eval_planning.py` 的 `l2_1s/2s/3s` 分别为前 2/4/6 个轨迹点的平均位移误差（ADE）。
- 论文 Avg. 是上述 1/2/3 秒三个指标再取算术平均。因此本次论文口径 Avg. L2 为 1.7985 m；`metrics.json` 中的 `mean_l2_m=2.5509` 是六个点的平均，也就是 3 秒 ADE，不能直接与论文 Avg. 1.80 m 比较。
- 单独 1/2/3 秒末端点的 L2 分别为 1.4121 / 2.8838 / 4.4974 m，不属于上表的 ADE。
- 发布评估器在每个时域内对碰撞取 max，即统计是否出现碰撞；越界同样统计时域内是否发生越界，并排除当前已在区域外的 recovery 情形。这些是开环几何事件率。

## 结果如何解释

1. **复现层面表现良好。** 均值与逐时域结果均接近论文；不存在把 SpaceDrive+ 的更低误差误当作当前权重目标的问题。
2. **短期优于长期。** ADE 从 1 秒 1.0595 m 增至 3 秒 2.5509 m；3 秒末端误差为 4.4974 m。3 秒内碰撞事件为 205/5119（4.0047%），越界事件为 431/5119（8.4196%）。两类事件可能重叠，不能相加为总失败率。
3. **开环均值不代表所有场景均稳定。** 按逐帧六点 ADE，样本中位数 1.9718 m，P90 为 5.1993 m，P95 为 6.8911 m；557 帧（10.88%）大于 5 m，68 帧（1.33%）大于 10 m，存在长尾误差。阈值仅用于描述结果。
4. **同设置基线比较有优势。** 相对论文中无 ego status 的 OmniDrive-Q（Avg. L2 1.98 m、碰撞 3.79%、越界 4.59%），本次三个均值分别降低约 9.17%、50.35%、7.50%。这是与论文报告基线的比较，没有在本机重跑基线。
5. **SpaceDrive+ 是另一设置。** 本次 `ego_status` 为空、`load_ego_command_in_question=false`；论文 SpaceDrive+ 加入自车历史动态与当前命令，Qwen 版本均值为 0.32 m / 0.23% / 1.27%。不可将这组结果作为当前普通版复现的目标。
